Приложение “BookFanApp” представляет собой сервис, позволяющий получать информацию о книжных изданиях с возможностью добавления в избранное. Проект написан на Kotlin и использует  Jetpack Compose для UI, Ktor для сетевых запросов, Room для локальной базы данных и Koin для внедрения зависимостей.

**Основной функционал приложения включает в себя**:
1. Получение списка книжных трендов.
2. Поиск книг по названию с использованием Open Library Api.
3. Просмотр доступной информации о книге: год публикации, количество страниц, рейтинг, описание и т.д.
4. Возможность добавлять книги в избранное, а также удалять их.
